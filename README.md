## 🏛️ Architectural Overview

The Rotunda Royale houses 140+ storied luxury houses, three-star Michelin culinary salons, and monolithic commercial flagship envelopes across 192,000 square metres of Gross Leasable Area (GLA) beneath a 44.5m double-curved structural glass diagrid canopy.

### Key Architectural Metrics
* **140+** Luxury Houses & Global Flagships *(Haute Horlogerie, Haute Couture & Joaillerie)*
* **192,000 m²** Gross Leasable Area across 4 architectural levels
* **16** Michelin Salons & Private Dining Ateliers *(equipped with independent 32,000 m³/h risers)*
* **1,400** Subterranean Armored Valet Bays *(Levels B1–B3 with 4 heavy logistics docks)*

## 🎨 Strict 6-Color Design System (No Gradients)

The visual identity strictly enforces an uncompromised 6-color system inspired by high-end Swiss architectural monographs and Apple minimalism. Zero multi-color rainbow gradients, zero fuzzy radial background blobs, and zero neon glows.

| Color Token | Hex Code | Purpose & Application |
|---|---|---|
| **DarkGrey** | `#1C1C1E` | Primary headings, body copy, and monolithic high-contrast typographic hierarchy |
| **White** | `#FFFFFF` | Primary clean gallery canvas, structural negative space, and crisp backgrounds |
| **LightBlush** | `#F7F4F4` | Subtle secondary section backgrounds, console fills, and technical surfaces |
| **LightGrey** | `#DADADA` | 1px hairline borders, structural dividers, CAD blueprint grid lines, and subtle outlines |
| **VividRed** | `#D92D20` | Primary accent, primary CTA pill buttons, active CAD blueprint pins, and telemetry beacons |
| **Navy** | `#1E3A5F` | Deep architectural secondary highlights, structural frames, and engineering badges |

### Typography Principles
* **Neo-Grotesque Display Sans**: Pure modern sans font stack (`Geist Sans`, `-apple-system`, `SF Pro Display`) with tight letter-spacing (`tracking-tight`, `-0.011em`) and bold weights for headlines.
* **Tracked Uppercase Micro-Labels**: Precision architectural telemetry labels (`tracking-[0.2em] uppercase text-[10px] font-semibold font-mono`).
* **Pill Geometry**: Fully rounded buttons (`rounded-full`) contrasting against razor-sharp 1px hairline dividers (`border-[#DADADA]`).

## 🚀 Getting Started

### Prerequisites
* Node.js 18+ (tested on Node v26)
* npm 9+

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone git@github.com:reachorion-ops/demos3.git
   cd demos3
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Verify production build & linter**:
   ```bash
   npm run lint
   npm run build
   npm start
   ```
